Télécharger l’application
  1. Ouvrez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre PC » : Plus d’infos puis Exécuter quand même.
  3. Suivez l’installation, puis ouvrez Paryaj Paw Boutik.
  4. Connectez-vous avec votre compte caissier (Internet requis).
